# FORMA / 01 — 3D Perspective Digital Art Exhibition (2026)

An award-winning, immersive, two-sided 3D architectural digital art exhibition gallery experience built for the web.

## Overview
**FORMA / 01** showcases a curated collection of 12 original contemporary artworks positioned along a curved perspective corridor. Visitors can smoothly explore the gallery using trackpad scroll, drag, or keyboard stepping, seamlessly transition into square-on front views, inspect detailed artist notes, and collect archival editions.

## Key Features
- **Two-Sided Perspective 3D Corridor**: Parametrically constructed curved architectural geometry with airtight wall, floor, and ceiling joins.
- **Cinematic Camera Transitions**: Smooth, natural interpolation between corridor walk-around mode and square-on front view inspections.
- **Curated 12-Piece Collection**: Original contemporary artworks with curated metadata, editions, and provenance.
- **Interactive Framed Artwork Modal & Room Previews**: Dynamic artwork detail pages with archival paper, sizing, signature, and frame customization.
- **Museum Aesthetic**: Minimalist Swiss/editorial typography (Montserrat), generous negative space, and modern museum lighting.
- **Collector Cart & Drawer**: Integrated cart drawer with edition selection and simulated checkout.

## Technology Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **3D Graphics Engine**: Three.js
- **Animations & Motion**: GSAP
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) to view the exhibition.
